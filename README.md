# 📧 Automated Payslip Generator & Email Sender (Python)

This project automates the generation of employee payslips from an Excel spreadsheet and sends them out via email using Python. It handles data cleaning, PDF creation, and secure email dispatch.

---

## 🚀 Features

- Loads employee salary data from Excel.
- Cleans and processes salary figures.
- Calculates Net Salary (Basic + Allowances - Deductions).
- Generates individual payslips as PDF files.
- Emails each payslip to the respective employee.
